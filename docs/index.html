About / How to use

What the model simulates

Each invited guest attends with probability p, so attendance is Binomial(N, p). Each attendee takes 0, 1, 2 or 3 portions with probabilities 0.05, 0.50, 0.35, 0.10 (mean 1.5). Guests arrive as a Poisson stream and queue for c stations with exponential service. Food is taken when service finishes; unmet demand is recorded if the pot runs dry.

How to run a simulation

Use Start, Pause, and Reset to explore one event. Speed is simulated minutes per real second. Changing a parameter takes effect on the next Start. Prepared portions Q is the decision variable.

How to interpret Monte Carlo results

Run 10,000 events reports means with 95% confidence intervals (1.96 s/√n). Total cost combines preparation cost and shortage penalty. If parameters differ from reference A, notebook comparisons are unavailable.

Reference checks

Reference A verifies the stochastic baseline against the notebook. Reference B is deterministic: with 50 guests taking exactly 2 portions and Q=90, demand is 100, so 90 are served and 10 are unmet.

All costs, consumption probabilities, arrival and service rates are assumed values, not measured data. Results illustrate the method and do not describe any real caterer. Random numbers use a seeded mulberry32 generator.
